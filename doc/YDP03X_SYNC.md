## 资源与构建

三代可编辑资源位于 `/home/haiku/build/qrc/ydp03x`。本仓库只保留生成的
`resource/models/YDP03X/qrc_qml.h`，不要手工编辑该文件。

在 PenMods 项目根目录执行：

```sh
bash scripts/gen_qt_res.sh /home/haiku/build/qrc/ydp03x resource/models/YDP03X
xmake f --qt=/home/haiku/program/qt --arch=arm64-v8a --build-platform=YDP03X \
  --target-channel=dev --toolchain=zigcc --cross=aarch64-linux-gnu.2.27 \
  -m release --force-debug-log=false -c -y
xmake build PenMods
xmake build PenModsResources
```

xmake/Zig 应在主机运行。若临时 `zigcc/c++` 路径失效，重新运行配置命令。
`scripts/unpack_qrc.py ... --check` 可以只读比较生成头与资源树。

## 手工部署

本轮没有连接设备。主库与资源库必须成对替换，本分支的默认路径是 `/userdisk/PenMods/`。
如果使用打包的验机文件，将命令中的构建路径换成解压后的同名库文件即可。
先传到临时文件再重命名，避免覆盖进程正在映射的库：

```sh
adb push build/linux/arm64-v8a/release/libPenMods.so /userdisk/PenMods/libPenMods.tmp.so
adb push build/linux/arm64-v8a/release/libPenModsResources.so /userdisk/PenMods/libPenModsResources.tmp.so
adb shell 'mv -f /userdisk/PenMods/libPenMods.tmp.so /userdisk/PenMods/libPenMods.so && mv -f /userdisk/PenMods/libPenModsResources.tmp.so /userdisk/PenMods/libPenModsResources.so && sync && killall YoudaoDictPen'
```

重启后检查最新应用日志中的 `ReferenceError`、`TypeError`、`is not a function` 和缺失符号消息。

## 三代 OTA 清单约定

更新源默认为空，界面显示“未设置三代更新源”。没有复用二代源或发布更新包。
配置源后，清单需包含当前版本，且根对象或各版本条目的 `platform` 为 `YDP03X`：

```json
{
  "status": 200,
  "platform": "YDP03X",
  "versions": [
    { "version": [2, 4, 0] }
  ]
}
```

更高版本条目需要 `version`、`note`、`size`、`download`、`md5`。下载文件为 ZIP，根目录包含
`_do_update.sh`、`libPenMods.so`、`libPenModsResources.so`。库必须是 ARM64 ELF 共享库，且带有本分支
生成的 `PenMods.Platform=YDP03X` 标记；MD5 或型号校验失败不会运行安装脚本。
安装脚本应成对更新 `/userdisk/PenMods/` 下的库，并仅在成功后创建 `INSTALL_SUCCESSFULLY`。

## 本次核对的宿主接口

符号与少量布局依据 `/home/haiku/build/pen/output/YoudaoDictPen` 及配套库核对：

- 三代打开音乐页使用 `YBaseSignalAggregate::showAudioPlayer()`，不使用二代的 `YGlobal` 方法。
- `YColumnMediaEntity` 构造/析构位于 `0x4e0efc` / `0x4e0fc8`，对象大小 `0x68`；实体通过原生 setter 写入，下载状态使用原生枚举接口。
- 音乐结束回调 `0x51c514` 使用管理器 `+0x28` 的私有指针和私有区 `+0x64` 的播放序号。
- 单词本 `onExecFinished` 在 `0x58f198` 读取查询结果 `+0x50` 的请求号；导出使用自己的请求号，不改宿主导出标志。
- 离线教材解包使用两个 `QString` 参数，空目标目录表示解压到 ZIP 所在目录。
